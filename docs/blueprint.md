# **App Name**: Neeshna's Codex

## Core Features:

- Interactive Trackers: Dynamic, editable PDF templates for habit tracking, GPA calculation, finance management, and coding skill progression (DSA, Leetcode).
- Comprehensive Logs: Integrated sections for internship/project tracking, tech event logs, club involvement records, and placement readiness assessment (resume, aptitude tests).
- Custom Academic Planner: A customizable academic planner covering 2025-2029, including yearly overviews, monthly planners, weekly schedules, and built-in to-do lists, tailored for both academic and personal goals.
- Inspiration Engine: Inspirational content powered by personalized goals.

## Style Guidelines:

- Primary color: Vintage Gold (#B8860B) to evoke a sense of timelessness and elegance, referencing historical documents and classic design.
- Background color: Deep Black (#121212), reminiscent of classic noir films and gothic architecture.
- Accent color: Burgundy (#800020), drawing inspiration from old books and subtle signs of richness.
- Typewriter Font: Use a monospaced typewriter font to be used throughout for headings. Example: 'PT Sans' (sans-serif)
- Gothic Serif Fonts: Use 'Literata' for titles.
- Mafia-glam icons throughout the planner; a design set of icons is used to reference the gothic theme (i.e. antique keys for securing goals).
- Utilize a grid-based layout system with dedicated space for textual notes and functional planning.
