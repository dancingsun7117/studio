

# ✦ Planner 25–29

> **“In a world full of noise, she codes in silence and conquers in power.”**

A personal **digital command center for 2025–2029**, designed to bring academics, productivity, personal growth, ideas, and long-term goals into one organized space.

🔗 **Live Demo:** [https://studio-7335.vercel.app/](https://studio-7335.vercel.app/)

---

## ✦ Overview

**Planner 25–29** is more than a traditional planner.

It is a personalized productivity dashboard built around the idea of turning long-term ambitions into daily action.

The application combines:

* 📊 Progress tracking
* 🎓 Academic planning
* 🗓️ Weekly scheduling
* 💡 Idea management
* 📝 Personal notes
* ✨ Daily motivation
* ❤️ Gratitude and reflection
* 🎯 Long-term goal management

The goal is simple:

> **Plan intentionally. Track consistently. Build your future one day at a time.**

## ✦ Features

### 🖤 Dashboard

The central command center of the planner.

It provides:

* Personalized welcome section
* Daily affirmation
* Personal mission
* Daily gratitude
* Quick access to planner modules
* Motivational elements

---

### 📊 Core Trackers

Track important areas of personal and academic progress from one place.

Use trackers to monitor consistency, progress, and long-term development.

### 🎓 Academic Planner

A dedicated space for managing academic responsibilities and planning progress throughout the academic journey.

Designed to help organize:

* Academic goals

* Important milestones

* Long-term academic planning

Plan your week and create a structured schedule around classes, study sessions, projects, and personal commitments.

This helps transform larger goals into actionable weekly plans.

### ✨ Motivation

* Motivational quotes

* Positive reinforcement

### 📝 Notes

A flexible workspace for capturing thoughts, information, reminders, and anything worth keeping.

### 💡 Ideas

A dedicated place to store ideas before they disappear.

Useful for:

* Project ideas

## ✦ Design Philosophy

Planner 25–29 follows a **dark-academia × elegant productivity** aesthetic.

The interface combines:

* Warm neutral backgrounds
* Burgundy accents
* Serif typography
* Minimal layouts
* Elegant cards
* Subtle decorative elements

The goal is to make productivity feel **personal, motivating, and visually enjoyable** rather than like another generic task-management application.

## ✦ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/dancingsun7117/studio.git
cd studio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

## ✦ Production Build

Create a production build with:

```bash
npm run build
```

Then start the production server:

```bash
npm start
```

## ✦ Why Planner 25–29?

Most productivity tools focus on isolated tasks.

Planner 25–29 is designed around a bigger question:

> **What am I building over the next five years?**

Instead of only tracking today's tasks, the planner connects:

**Vision → Goals → Academics → Weekly Planning → Daily Action → Progress**

It is intended to become a personal operating system for the journey from **2025 to 2029**.
